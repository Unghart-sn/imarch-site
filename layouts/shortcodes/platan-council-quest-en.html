Basic Initiation Quest

👤

GitHub Account

The institutional Game requires a GitHub account: personal or organizational.

Minimum requirement: Verified email, public profile

🎭

Game Account

We strongly recommend creating a separate game account, specifically for participation in missions.

Recommendation: Name reflects your role in the ecosystem

⚡

Activation

After creating and verifying the account, you receive the Player status in the consortium system.

Process: Automatic verification via GitHub API

🛡️

Strategic Recommendation

A separate game account is not merely a technical formality. It is the creation of an institutional mask, a role‑based identity that allows participation in the Game without mixing with personal or commercial activities.

🎯

Player Status

After activation, you gain access to the choice of entry format into the Game. This status unlocks all scenes and missions of the Project, but does not grant automatic rights to participate — only the ability to request access.

Entry Formats into the Game

👁️

Observer

Access to public materials, reading discussions, participation in open events without voting rights.

🤝

Participant

Inclusion in working groups, participation in discussions, task execution with mentor support.

⚔️

Missionary

Full access to scenes, right to create initiatives, participation in strategic decision‑making.

COMPLETE QUEST

After completing the quest you will receive access to the participation format selection form and instructions for further initiation into specific Council scenes.
