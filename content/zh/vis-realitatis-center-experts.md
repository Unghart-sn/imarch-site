####  📖 Chronicle OS：科学计量期刊与出版平台 { .fade-in-up }

**Chronicle OS** 是一本国际性、跨学科、开放获取的同行评审期刊，融入 IMARCH LTD 的基础设施。

该期刊提供：

- **双盲同行评审**
- **文章的加密预注册**和假设（SHA‑256 哈希）
- **DOI 分配**以及在国际数据库中的索引（DOAJ、Scopus、WoS — 远景）
- **开放的资助模式**（合理的 APC，可全额免除）

通过在 Chronicle OS 发表，您将您的科学成果嵌入一个受保护、可验证并可资本化的生态系统。

#### 背景 { .fade-in-up }

IMARCH 的诞生是为了回应这样一个缺失：一个深层实践无需为了可见性而简化的空间。

该结构在人道主义倡议、研究过程和应用学科的交汇处发展。

环境中已经形成了不同的实践方向。一些参与者工作在科学与治疗的边界。另一些发展手工艺和身体导向的方法。一部分探索新的互动形式和社会结构。

#### 我们在寻找谁 { .fade-in-up }

我们更多关注实践的深度而非地位。

我们感兴趣的是研究人员、治疗师、工程师、应用学科大师、导师、方法作者和独特经验的持有者。

**我们特别欢迎那些希望：**

- 在开放获取的同行评审期刊上发表文章并为其工作获得 DOI；
- 参与科学计量平台的发展；
- 影响新研究生态系统的形成。

如果您的工作不适合标准类别，这可能是一个契合的信号。

#### 优先领域与参与者画像 { .fade-in-up }

编辑委员会关注研究的学术和实践深度，优先考虑具有可验证应用经验的作者。

我们邀请研究人员、执业治疗师、工程师、专有方法作者、导师和拥有独特经验数据的跨学科专家进行长期合作。

互动计划面向以下感兴趣的作者：

**成果的存放与验证**：在开放获取的同行评审期刊上发表，并强制分配国际 DOI。

**基础设施发展**：专家参与科学计量平台的方法和技术形成。

**制度整合**：加入国际研究生态系统和轮廓项目。

出版商的特别关注点是那些处于多个科学领域交叉点的非标准、跨学科工作，这些工作需要单独评审。
