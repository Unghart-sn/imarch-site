#### Зачем нужен цифровой сейф { .fade-in-up }

В рабочей практике ценность материалов часто теряется не из-за недостатка места, а из-за отсутствия порядка. Документы распределяются между переписками, локальными папками и различными сервисами, версии смешиваются, а важные артефакты остаются без единой системы хранения.

Цифровой сейф создаёт отдельный управляемый контур для материалов, которым необходимы организованное хранение и предсказуемый доступ.

{{< ts-panel >}}
Он подходит:

* **Владельцам сертификатов временной метки и паспортов артефактов.** Для хранения зарегистрированных материалов, сертификатов, криптографических идентификаторов, цифровых копий и сопутствующей документации в одном пространстве.
* **Авторам, исследователям и специалистам.** Для размещения ключевых рукописей, схем, спецификаций, договоров, технической документации и итоговых версий без смешивания с черновиками и повседневными файлами.
* **Проектам и участникам экосистемы IMARCH / Chronicle OS.** Для структурированного размещения рабочих материалов, защищённых пакетов, ревизий, документальных записей и связанных объектов.
* **Пользователям, которым важны порядок и контроль.** Когда объём материалов невелик, но ценность каждого файла высока, приоритетом становится организованное хранение, а не безлимитное пространство для медиаконтента.
{{< /ts-panel >}}

#### Объём хранения и расширение { .fade-in-up }

{{< ts-panel >}}
<div class="ts-panel-title">Базовый контур · 100 МБ</div>
Стартовый объём для компактного набора документов, сертификатов, спецификаций, цифровых копий, архивов и рабочих материалов.

Базовый объём позволяет начать пользоваться сейфом без необходимости заранее приобретать дополнительное пространство.
{{< /ts-panel >}}

{{< ts-panel >}}
<div class="ts-panel-title">Дополнительный объём · +100 МБ за £5</div>
Если объём материалов увеличивается, хранилище можно расширять последовательными шагами по 100 МБ.

Стоимость каждого дополнительного шага составляет £5 по подписке.

Вы подключаете только необходимый объём, постепенно масштабируя пространство в соответствии с текущими задачами.
{{< /ts-panel >}}

{{< ts-panel >}}
<div class="ts-panel-title">Режим при прекращении продления</div>
Если подписка на дополнительный объём не продлена, цифровой сейф переводится в режим **«Только чтение / скачивание»**.

Сохранённые файлы остаются доступными для просмотра и скачивания. Пользователь может забрать свои материалы без необходимости немедленно продлевать подписку.

В этом режиме новые файлы не загружаются, а изменение содержимого ограничивается условиями режима доступа.
{{< /ts-panel >}}

#### Частые вопросы { .fade-in-up }

{{< details "Подходит ли сейф для хранения больших видеороликов и медиатек?" >}}
Нет. Цифровой сейф предназначен для компактного хранения значимых материалов: документов, сертификатов, цифровых копий, архивов, технических спецификаций и защищённых пакетов.

Он не позиционируется как массовое медиахранилище или безлимитный диск для больших видеоархивов.
{{< /details >}}

{{< details "Что происходит, если я исчерпал доступный объём?" >}}
Загрузка новых файлов сверх текущего лимита прекращается до подключения дополнительного шага хранения.

Вы можете увеличить объём на 100 МБ за £5 по подписке.
{{< /details >}}

{{< details "Удаляются ли мои файлы, если я не продлю подписку на дополнительный объём?" >}}
Нет. При прекращении продления предусмотрен переход в режим «Только чтение / скачивание». Сохранённые материалы остаются доступными для просмотра и получения.
{{< /details >}}

{{< details "Можно ли хранить в сейфе сертификаты временной метки?" >}}
Да. Сейф предназначен в том числе для хранения сертификатов, регистрационных данных, цифровых копий зафиксированных материалов и сопутствующих документов.
{{< /details >}}

{{< details "Можно ли расширять объём постепенно?" >}}
Да. Дополнительное пространство подключается шагами по 100 МБ. Вы можете наращивать доступный объём по мере необходимости.
{{< /details >}}

{{< details "Является ли цифровой сейф резервной копией моего компьютера?" >}}
Нет. Это отдельный контур хранения цифровых материалов. Он не заменяет полноценную систему резервного копирования, архивирования или восстановления данных.
{{< /details >}}
