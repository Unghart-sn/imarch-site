#### Зачем нужна фиксация времени { .fade-in-up }

В профессиональной и творческой деятельности нередко возникает необходимость подтвердить, что конкретный материал уже существовал в определённом виде до публикации, передачи третьим лицам, начала переговоров, последующей редакции или другого значимого события.

Сертификат отметки времени создаёт проверяемую запись, связанную с цифровым объектом и моментом его регистрации.

{{< ts-panel >}}
Он может применяться для фиксации:

* рукописей, текстов, концепций и исследовательских материалов;
* визуальных произведений, фотографий, дизайна и музыкальных композиций;
* программного кода, технических схем, архитектурных решений и спецификаций;
* расчётов, аналитических отчётов, проектных документов и промежуточных результатов;
* версий предложений, рабочих материалов и документов, относящихся к определённому этапу проекта.
{{< /ts-panel >}}

Смысл процедуры заключается в создании проверяемого временного ориентира, который может использоваться в дальнейшем при сопоставлении версий, подтверждении хронологии и представлении документальных материалов.

Практичный цифровой подарок человеку, который создаёт, исследует, проектирует или развивает собственный проект.

Подарочный сертификат предоставляет возможность самостоятельно выбрать цифровой объект и момент его регистрации.

**Как это работает:**

1. Покупатель приобретает подарочный сертификат.
2. Получает уникальный код активации.
3. Передаёт код получателю любым удобным способом.

5. Использует его для регистрации собственного цифрового объекта.

Предварительная привязка к аккаунту, адресу электронной почты или конкретному файлу не требуется.

Подарок предоставляет одну процедуру регистрации в соответствии с условиями активации.

Данный сценарий предназначен для пользователей, которым необходим дополнительный контроль над обработкой конфиденциальных, профессиональных, исследовательских или иных материалов.

#### Частые вопросы { .fade-in-up }

{{< details "Что подтверждает сертификат отметки времени?" >}}
Он содержит проверяемую запись, связанную с цифровым объектом и зафиксированным моментом времени. С учётом технических свойств и корректности процедуры фиксации он может помочь установить, что соответствующие цифровые данные существовали в определённой форме не позднее зафиксированного времени.
{{< /details >}}

{{< details "Подтверждает ли сертификат авторство или право собственности?" >}}
Нет. Сертификат отметки времени не устанавливает самостоятельно авторство, право собственности, оригинальность, права интеллектуальной собственности или юридическую действительность документа. Он может служить подтверждающим доказательством в совокупности с другими записями и доказательствами.
{{< /details >}}

{{< details "Хранит ли IMARCH мой исходный файл?" >}}
Исходный файл обрабатывается для вычисления его криптографического хеша. После завершения процедуры регистрации он не сохраняется в инфраструктуре.
{{< /details >}}

{{< details "Можно ли зарегистрировать конфиденциальный материал?" >}}
Стандартная процедура регистрации не сохраняет исходный файл после завершения. Пользователям, работающим с особо конфиденциальными материалами, может быть доступен режим регистрации только хеша, при котором регистрируется заранее вычисленный криптографический хеш без загрузки исходного файла.
{{< /details >}}

{{< details "Можно ли использовать сертификат в судебном разбирательстве?" >}}
Он может быть представлен как подтверждающее доказательство с учётом применимого права, характера спора и оценки соответствующего органа. Сертификат не заменяет юридическую консультацию, экспертизу или иные доказательства.
{{< /details >}}

{{< details "Можно ли передать сертификат другому человеку?" >}}
Да. Подарочный сертификат выдаётся с уникальным кодом активации, который можно передать другому лицу. Получатель активирует код на сайте и использует право на регистрацию для своего цифрового объекта.
{{< /details >}}

{{< details "Сколько регистраций входит в профессиональный пакет?" >}}
Профессиональный пакет включает пять независимых регистраций за £90. Каждую регистрацию можно использовать для отдельного цифрового объекта или версии.
{{< /details >}}
