#### Статус проекта VIS REALITATIS™ { .fade-in-up }

Проект центра реновации и социальной адаптации ветеранов VIS REALITATIS™ является базовым производственным проектом IMARCH LTD (Великобритания), реализуемым в рамках широкой институциональной инфраструктуры Chronicle OS Documentation System.

На текущем этапе формируется базовое ядро системы и первый реестр сооснователей и участников.

Включение и определение ранга сооснователя производится на основании экспертного и/или финансового вклада в развитие проекта, под гарантиями IMARCH LTD (UK).

Институциональная инфраструктура: Chronicle OS Documentation System
