#### ЗАФИКСИРУЙТЕ СВОЙ ПРИОРИТЕТ В МИРОВОЙ НАУКЕ ЗА 7 ДНЕЙ { .fade-in-up }

**VERDICTUM International Journal** (Издательство IMARCH LTD, Лондон, Великобритания) объявляет приём разработок, исследований и ноу-хау.

> Мы внедрили систему криптографического рецензирования (Skin-in-the-Game), защищающую вашу интеллектуальную собственность с первой секунды подачи.

&nbsp;

#### Сквозные стандарты верификации и беспристрастности { .fade-in-up }

- **Double-Blind Peer Review (Абсолютно слепое рецензирование)**: Исключает человеческий фактор, предвзятость или академический протекционизм. Рецензент оценивает только качество работы, не зная имени автора, его страны или университета.

- **Криптографическая фиксация приоритета (SHA-256)**: Платформа решает главную проблему авторов — защиту интеллектуальной собственности в процессе рассмотрения. Хэш вашего слепого вектора и мастер-файла публикуется мгновенно, закрепляя за вами первенство идеи в международном цифровом пространстве.

- **Skin-in-the-Game для рецензентов**: Экспертиза в VERDICTUM — это экономика участия. Рецензент получает вознаграждение за аудит сразу и разделяет долгосрочный процент от успеха проекта. Его вердикт — это финансово и репутационно обеспеченный знак качества.

#### Публикационный контур и инфраструктурный взнос (APC) { .fade-in-up }

*Платформа VERDICTUM функционирует как некоммерческая инфраструктура суверенного знания. Мы не торгуем «местами в журналах». Целевые взносы авторов направляются на покрытие расходов по независимой оценке, криптографической фиксации и международной регистрации.*

**Структура целевого финансирования:**

* **£50: Целевой регистрационный взнос.** Вносится при первичной подаче. Покрывает расходы на первичный аудит, фиксацию SHA-256, работу реестра Verdictum Record (VR) и подготовку материалов для независимого эксперта.

* **£100: Финальный публикационный взнос.** Вносится **только после** того, как работа успешно прошла слепое рецензирование и утверждена к фиксации. Покрывает генерацию DOI, индексацию в реестре VERDICTUM и официальный релиз.

Целевая поддержка некоммерческой инфраструктуры VERDICTUM обеспечивает приоритетные сроки обработки и первичной технической валидации. При этом все работы без исключения проходят независимое слепое рецензирование. Взнос покрывает организацию процесса и не гарантирует положительного решения рецензентов.

#### Шаг 1. Пакет безопасности (Подача заявки) { .fade-in-up }

Вы загружаете в форму два файла вашей работы в формате PDF или Word:

1. **Мастер-Файл:** Полная версия (Ваше имя, Вуз/организация, контакты, аннотация, текст). Он сразу уходит в наше закрытое зашифрованное хранилище (Secure Vault).

2. **Слепой Вектор:** Абсолютно идентичный текст работы, но из него **полностью удалены ваши реквизиты, имя и название организации**. Только чистая суть.

#### Шаг 2. Криптографический Замок (Мгновенный приоритет) { .fade-in-up }

В ту же секунду, как файлы загружены, наша система вычисляет их уникальные цифровые отпечатки — **хэши SHA-256**.

* Мы публикуем карточку вашей работы на открытой витрине предпубликаций `imarch.ltd`.

* **Ваше имя скрыто от всех.** Но в открытом доступе висит аннотация и хэши ваших файлов.

* *Зачем это нужно?* Это ваш железный щит. Поисковые системы мгновенно индексируют страницу. Ваша идея защищена от воровства на 100%. Если кто-то попытается заимствовать вашу формулу во время рецензирования, у вас есть лондонское доказательство приоритета.

#### Шаг 3. Абсолютно слепое рецензирование (До 7 дней) { .fade-in-up }

Мы берем ваш **Слепой Вектор** (файл без имени) и отправляем его независимому международному эксперту из нашей Редколлегии.

* Эксперт оценивает исключительно качество вашего исследования. Он не знает, из какой вы организации и из какой страны. Полная беспристрастность.

* Регистрационный взнос £50 обеспечивает оперативность аудита и покрывает технические расходы на проведение рецензирования в течение 7 дней.

#### Шаг 4. Вскрытие сейфа и Релиз { .fade-in-up }

Как только рецензент ставит визу «Одобрено», вы получаете уведомление.

* Вы вносите финальный публикационный взнос £100.

* Система автоматически достает ваше имя из закрытого сейфа, связывает его с ранее опубликованным хэшем Мастер-Файла, присваивает работе международный индекс **DOI** и переводит статус в «Официально зафиксировано».

async function generateFileHash(inputId, displayId) {
  const input = document.getElementById(inputId);
  const display = document.getElementById(displayId);
  if (!input.files || input.files.length === 0) {
    display.innerText = "SHA-256: ожидание файла...";
    return;
  }
  const file = input.files[0];
  display.innerText = "Расчёт SHA-256 хеша...";
  try {
    const arrayBuffer = await file.arrayBuffer();
    const hashBuffer = await crypto.subtle.digest('SHA-256', arrayBuffer);
    const hashArray = Array.from(new Uint8Array(hashBuffer));
    const hashHex = hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
    display.innerText = "SHA-256: " + hashHex;
    sessionStorage.setItem('auth_' + inputId + '_hash', hashHex);
  } catch(e) {
    display.innerText = "SHA-256: Ошибка вычисления хеша";
  }
}
