#### ЗАФИКСИРУЙТЕ СВОЙ ПРИОРИТЕТ В МИРОВОЙ НАУКЕ ЗА 7 ДНЕЙ { .fade-in-up }

Международный рецензируемый междисциплинарный научный журнал **«IMARCH Chronicle OS»**, (Издательство IMARCH LTD, Лондон, Великобритания) объявляет прием публикаций в *Volume 1, Issue 1 (May-June 2026)*. 

> Мы внедрили систему слепого криптографического рецензирования, защищающую вашу интеллектуальную собственность с первой секунды подачи заявки.

&nbsp;

#### Сквозные стандарты академической безопасности и беспристрастности { .fade-in-up }

- **Double-Blind Peer Review (Абсолютно слепое рецензирование)**: Исключает человеческий фактор, предвзятость или академический протекционизм. Рецензент оценивает только качество исследования, не зная имени автора, его страны или университета.

- **Криптографическая фиксация приоритета (SHA-256)**: Наша платформа решает главную проблему авторов — защиту интеллектуальной собственности в процессе рассмотрения. Хэш вашего слепого вектора и мастер-файла публикуется мгновенно, закрепляя за вами первенство идеи в международном цифровом пространстве.

- **Оптимизированный регламент (Без бюрократических издержек)**: Мы убрали многомесячные административные задержки. Автоматизированный контур обработки метаданных позволяет провести аудит и рецензирование в фиксированный 7-дневный срок без потери академического качества.

#### Публикационный контур и инфраструктурный оргвзнос (APC) { .fade-in-up }

*Платформа IMARCH функционирует как некоммерческая инфраструктура открытой науки. Мы не торгуем «местами в журналах». Целевые взносы авторов направляются на покрытие расходов по высокотехнологичной независимой оценке, криптографической фиксации и международной регистрации.*

**Структура целевого финансирования:**

* **£50: Целевой регистрационный взнос (Suggested Infrastructure Grant).** Вносится при первичной подаче. Покрывает расходы на первичный ИИ-аудит антиплагиата, фиксацию SHA-256, работу сервера реестра RN-0030 и подготовку материалов для независимого эксперта.

* **£100: Финальный публикационный взнос.** Вносится **только после** того, как статья успешно прошла слепое рецензирование и утверждена к публикации. Покрывает генерацию британского DOI, вечную индексацию на серверах и официальный релиз.

Целевая поддержка некоммерческой инфраструктуры IMARCH Chronicle OS позволяет обеспечивать приоритетные сроки обработки и первичной технической валидации рукописи. При этом все статьи без исключения проходят независимое слепое рецензирование (Double-Blind Peer Review). Взнос покрывает организацию процесса и не гарантирует положительного решения рецензентов.

#### Шаг 1. Пакет безопасности (Подача заявки) { .fade-in-up }

Вы загружаете в форму два файла вашей статьи в формате PDF или Word:

1. **Мастер-Файл:** Полная версия (Ваше имя, Вуз, контакты, аннотация, текст). Он сразу уходит в наше закрытое зашифрованное хранилище (Сейф).

2. **Слепой Вектор:** Абсолютно идентичный текст статьи, но из него **полностью удалены ваши реквизиты, имя и название вуза**. Только чистая наука.


#### Шаг 2. Криптографический Замок (Мгновенный приоритет) { .fade-in-up }

В ту же секунду, как файлы загружены, наша система вычисляет их уникальные цифровые отпечатки — **хэши SHA-256**.

* Мы публикуем карточку вашей статьи на открытой международной витрине предпубликаций `imarch.sbs`.

* **Ваше имя скрыто от всех.** Но в открытом доступе висит английская аннотация и хэши ваших файлов.

* *Зачем это нужно?* Это ваш железный щит. Поисковые системы мгновенно индексируют страницу. Ваша идея защищена от воровства на 100%. Если кто-то попытается заимствовать вашу формулу во время рецензирования, у вас есть лондонское доказательство приоритета.


#### Шаг 3. Абсолютно слепое рецензирование (До 7 дней) { .fade-in-up }

Мы берем ваш **Слепой Вектор** (файл без имени) и отправляем его независимому международному эксперту из нашего Редсовета.

* Профессор оценивает исключительно качество вашего исследования. Он не знает, из какого вы университета и из какой страны. Полная беспристрастность.

* Регистрационный взнос £50 обеспечивает оперативность аудита и покрывает технические расходы на проведение рецензирования в течение 7 дней.


#### Шаг 4. Вскрытие сейфа и Релиз { .fade-in-up }

Как только рецензент ставит визу «Одобрено», вы получаете уведомление.

* Вы вносите финальный публикационный взнос £100.

* Система автоматически достает ваше имя из закрытого сейфа, связывает его с ранее опубликованным хэшем Мастер-Файла, присваивает статье международный индекс **DOI** и переводит статус публикации в статус «Официально издано».

async function generateFileHash(inputId, displayId) {
  const input = document.getElementById(inputId);
  const display = document.getElementById(displayId);
  if (!input.files || input.files.length === 0) {
    display.innerText = "SHA-256: ожидание файла...";
    return;
  }
  const file = input.files[0];
  display.innerText = "Расчет SHA-256 хеша...";
  try {
    const arrayBuffer = await file.arrayBuffer();
    const hashBuffer = await crypto.subtle.digest('SHA-256', arrayBuffer);
    const hashArray = Array.from(new Uint8Array(hashBuffer));
    const hashHex = hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
    display.innerText = "SHA-256: " + hashHex;
    sessionStorage.setItem('auth_' + inputId + '_hash', hashHex);
  } catch(e) {
    display.innerText = "SHA-256: Ошибка вычисления хеша";
  }
}
