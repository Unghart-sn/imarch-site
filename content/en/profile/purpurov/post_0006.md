But the value of scientific thought is determined by two conditions: it must not be trivial, and at the same time it must remain connected to what is already known – differing so originally that it is immediately apparent the thought is new, yet rooted in a responsible context.

This is precisely what makes the scientometric format valuable: it cuts off random utterances and records only those ideas that possess sufficient completeness and impeccability. If a thought does not withstand this test, it does not survive in the scientific world and is of interest to no one. But if it is framed in such a format – it is no longer graffiti on a fence, but the result of labour that has value and continuity.
