#### Why this is not a marketplace template { .fade-in-up }

A template provides a visual shell. It leaves the author responsible for argument structure, terminology, timing, information hierarchy, production coordination and final quality control.

PASSPORT-PACK provides a managed production result.

Every presentation block is assembled according to an approved specification. The production logic is documented, acceptance criteria are defined in advance, and the delivered artefact is evaluated against the agreed requirements rather than subjective design preferences.

**The result is a presentation artefact with a defined production protocol, documented configuration and controlled acceptance.**
