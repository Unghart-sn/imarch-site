This fundraiser is **not about "general support"**, but about a **specific first stage**, without which the project **cannot start safely and sustainably**.

**Stage 1 Goal** — lay the foundation:
- validate the methodology,
- create MVP organizational software,
- prepare prototypes (suit and mobile cabin),
- conduct the first pilot with documented results.

**Stage 1 Target Amount: $10,000**  
Implementation timeline: **10–12 weeks**.

## 🧩 Detailed Breakdown by Expense Items

### Research and Negotiations — $2,200
- Payment for initial expert consultations ($500 + $500)
- Technical specification preparation
- Questionnaires and focus groups
- Negotiations with suppliers and partners

### Methodology and Materials — $2,200
- Session scenarios and protocols
- Questionnaires and assessment tools
- Gamification elements
- Animation and printed materials

### MVP Organizational Software — $2,800
- Backend and frontend
- Participant profile
- Cost calculation module
- Simple referral logic
- Blog module for report publication
- Basic analytics and testing

### Prototypes — $1,800
- Suit cost calculation (unit / batch)
- 1–2 experimental samples
- Mobile massage cabin mockup
- Requesting offers from manufacturers

### Admin / Logistics / Reserve — $600
- Transport and communication
- Photo and video documentation
- Unforeseen expenses

---

## ⏳ Implementation Timeline (12 weeks)

- **Weeks 1–2:**  
  Negotiations, expert payments, research specification formation.
- **Weeks 3–6:**  
  Research, methodology development, first training materials.
- **Weeks 5–10:**  
  Software MVP development (2–3 sprints), prototype supplier work.
- **Weeks 11–12:**  
  Field pilot, data collection, photo/video, final report.

---

## 🧠 MVP Org-Software: Minimal Feature Set

**Focus — don't spread thin, make the core stable.**

1. User profile  
2. Cost calculation module  
3. Referral system  
4. Blog module (reports and publications)  
5. Simple report export (PDF / HTML)

---

## 📊 Stage 1 KPI (Clear and Measurable)

- Validated methodology (document, yes/no)
- At least **5 training artifacts**
- Working MVP software (profile + calculation + blog)
- 1 suit sample and cabin cost estimate
- Minimum **1 pilot event conducted**
- Report prepared with photos, video, and financial summary

---

## 🧭 Pilot Scenario (Brief)

- Preparation: methodology approval, recruiting 8–12 participants, logistics
- **Day 1:** introduction, questionnaires, method demonstration
- **Day 2:** practical sessions, feedback collection
- Report: 1-page summary + visual materials

---

## ⚠️ Risks and Mitigation Measures

- **Risk:** MVP overload  
  **Measure:** strict scope (3–5 features)
- **Risk:** unreliable suppliers  
  **Measure:** minimum 2–3 offers, test samples
- **Risk:** ethical dramatization  
  **Measure:** pilot before public stories, participant consent

---

## 🧱 Why This is Important

This stage is the **foundation of the entire system**.  
Without it, it's impossible to:
- scale help,
- ensure transparency,
- connect partners and donors in subsequent stages.

**By supporting Stage 1, you create the foundation of a project that can work for years, not months.**
