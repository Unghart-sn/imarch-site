#### Навіщо потрібна часова фіксація { .fade-in-up }

У професійній і творчій діяльності часто виникає потреба підтвердити, що конкретний матеріал уже існував у певному вигляді до публікації, передавання третім особам, початку переговорів, подальшого редагування або іншої значущої події.

Сертифікат часової мітки створює перевірюваний запис, пов'язаний із цифровим об'єктом і моментом його реєстрації.

{{< ts-panel >}}
Він може застосовуватися для фіксації:

* рукописів, текстів, концепцій і дослідницьких матеріалів;
* візуальних творів, фотографій, дизайну та музичних композицій;
* програмного коду, технічних схем, архітектурних рішень і специфікацій;
* розрахунків, аналітичних звітів, проєктної документації та проміжних результатів;
* версій пропозицій, робочих матеріалів і документів, що стосуються певного етапу проєкту.
{{< /ts-panel >}}

Суть процедури полягає у створенні перевірюваного часового орієнтира, який надалі може використовуватися для зіставлення версій, підтвердження хронології та представлення документальних матеріалів.

#### Додатковий режим реєстрації { .fade-in-up }

{{< ts-panel >}}
<div class="ts-panel-title">Hash-Only Registration</div>
<div class="ts-panel-meta">Реєстрація готового криптографічного хешу</div>
Для користувачів, яким принципово не передавати вихідний файл до реєстраційного інтерфейсу, може застосовуватися окремий сценарій реєстрації готового криптографічного хешу.

У цьому режимі користувач самостійно формує хеш свого цифрового об'єкта та передає до реєстраційної процедури лише його значення.

Це дає змогу здійснювати реєстрацію без завантаження вихідного файлу.

Такий сценарій призначений для користувачів, яким потрібен додатковий контроль над обробкою конфіденційних, професійних, дослідницьких або інших матеріалів.

Доступність і умови застосування цього режиму визначаються відповідною реєстраційною процедурою.

Він може використовуватися як додатковий документальний матеріал під час:

* зіставлення різних версій цифрового об'єкта;
* підтвердження послідовності розроблення або створення матеріалу;
* документування проміжних результатів;
* передавання матеріалів партнерам, замовникам, експертам або дослідницьким організаціям;
* підготовки доказової бази в межах конкретної правової чи професійної ситуації.

#### Часті запитання { .fade-in-up }

{{< details "Що підтверджує сертифікат часової мітки?" >}}
Він надає перевірюваний запис, пов'язаний із цифровим об'єктом і зареєстрованою часовою міткою. За умови належної технічної процедури він може допомогти підтвердити, що відповідні цифрові дані існували в певному вигляді не пізніше зафіксованого моменту часу.
{{< /details >}}

{{< details "Чи підтверджує сертифікат авторство або право власності?" >}}
Ні. Сертифікат часової мітки самостійно не встановлює авторство, право власності, оригінальність, права інтелектуальної власності або юридичну чинність документа. Він може бути додатковим доказовим матеріалом у сукупності з іншими записами та доказами.
{{< /details >}}

{{< details "Чи зберігає IMARCH мій вихідний файл?" >}}
Вихідний файл обробляється для формування криптографічного хешу. Після завершення процедури реєстрації він не зберігається в інфраструктурі.
{{< /details >}}

{{< details "Чи можу я зареєструвати конфіденційний матеріал?" >}}
Стандартна процедура реєстрації не передбачає збереження вихідного файлу після завершення процедури. Користувачі, які працюють із матеріалами високої конфіденційності, також можуть розглянути режим Hash-Only Registration, якщо він доступний. Він дає змогу зареєструвати заздалегідь сформований криптографічний хеш без завантаження вихідного файлу.
{{< /details >}}

{{< details "Чи можна використовувати сертифікат у судовому провадженні?" >}}
Він може бути представлений як додатковий доказ, залежно від застосовного законодавства, характеру спору та оцінки відповідного органу. Сертифікат не замінює юридичну консультацію, експертне дослідження або інші докази.
{{< /details >}}

{{< details "Чи можу я подарувати сертифікат іншій людині?" >}}
Так. Подарунковий сертифікат видається з унікальним кодом активації, який можна передати іншій особі. Отримувач активує код через сайт і використовує право на реєстрацію для власного цифрового об'єкта.
{{< /details >}}

{{< details "Скільки реєстрацій входить до Professional Pack?" >}}
Professional Pack містить п'ять незалежних реєстрацій за £90. Кожну реєстрацію можна використати для окремого цифрового об'єкта або його версії.
{{< /details >}}
