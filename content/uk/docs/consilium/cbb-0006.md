#### Керований контур зберігання ключових артефактів, сертифікатів, цифрових копій і документів в екосистемі IMARCH LTD / Chronicle OS. { .fade-in-up }

{{< steel_button link="#presentation" text="Презентація" >}}

Цифровий сейф призначений для матеріалів, яким потрібен окремий, упорядкований простір зберігання, а не випадкові папки, месенджери чи універсальні хмарні сховища.

Це компактний цифровий простір для ключових файлів, сертифікатів, зареєстрованих об'єктів, паспортів артефактів і документів, до яких необхідно повертатися з передбачуваним режимом доступу.

#### Навіщо потрібен цифровий сейф { .fade-in-up }

У робочій практиці цінність матеріалів часто втрачається не через нестачу місця, а через відсутність порядку. Документи розподіляються між листуванням, локальними папками та різними сервісами, версії змішуються, а важливі артефакти залишаються без єдиної системи зберігання.

Цифровий сейф створює окремий керований контур для матеріалів, яким необхідні впорядковане зберігання та передбачуваний доступ.

{{< ts-panel >}}
Він підходить:

* **Власникам сертифікатів часової мітки та паспортів артефактів.** Для зберігання зареєстрованих матеріалів, сертифікатів, криптографічних ідентифікаторів, цифрових копій і супровідної документації в одному просторі.
* **Авторам, дослідникам і фахівцям.** Для розміщення ключових рукописів, схем, специфікацій, договорів, технічної документації та фінальних версій без змішування з чернетками й повсякденними файлами.
* **Проєктам і учасникам екосистеми IMARCH / Chronicle OS.** Для структурованого розміщення робочих матеріалів, захищених пакетів, ревізій, документальних записів і пов'язаних об'єктів.
* **Користувачам, яким важливі порядок і контроль.** Коли обсяг матеріалів невеликий, але цінність кожного файлу висока, пріоритетом стає впорядковане зберігання, а не безлімітний простір для медіаконтенту.

#### Обсяг зберігання та розширення { .fade-in-up }

{{< ts-panel >}}
<div class="ts-panel-title">Базовий контур · 100 МБ</div>
Стартовий обсяг для компактного набору документів, сертифікатів, специфікацій, цифрових копій, архівів і робочих матеріалів.

Базовий обсяг дає змогу почати користуватися сейфом без необхідності заздалегідь придбавати додатковий простір.
{{< /ts-panel >}}

{{< ts-panel >}}
<div class="ts-panel-title">Додатковий обсяг · +100 МБ за £5</div>
Якщо обсяг матеріалів збільшується, сховище можна розширювати послідовними кроками по 100 МБ.

Вартість кожного додаткового кроку становить £5 за підпискою.

Ви підключаєте лише необхідний обсяг, поступово масштабуючи простір відповідно до поточних завдань.
{{< /ts-panel >}}

{{< ts-panel >}}
<div class="ts-panel-title">Режим у разі припинення продовження</div>
Якщо підписку на додатковий обсяг не продовжено, цифровий сейф переводиться в режим **«Лише читання / завантаження»**.

Збережені файли залишаються доступними для перегляду та завантаження. Користувач може забрати свої матеріали без необхідності негайно продовжувати підписку.

У цьому режимі нові файли не завантажуються, а зміна вмісту обмежується умовами режиму доступу.
{{< /ts-panel >}}

#### Часті запитання { .fade-in-up }

{{< details "Чи підходить сейф для зберігання великих відеороликів і медіатек?" >}}
Ні. Цифровий сейф призначений для компактного зберігання значущих матеріалів: документів, сертифікатів, цифрових копій, архівів, технічних специфікацій і захищених пакетів.

Він не позиціонується як масове медіасховище або безлімітний диск для великих відеоархівів.
{{< /details >}}

{{< details "Що відбувається, якщо я вичерпав доступний обсяг?" >}}
Завантаження нових файлів понад поточний ліміт припиняється до підключення додаткового кроку зберігання.

Ви можете збільшити обсяг на 100 МБ за £5 за підпискою.
{{< /details >}}

{{< details "Чи видаляються мої файли, якщо я не продовжу підписку на додатковий обсяг?" >}}
Ні. У разі припинення продовження передбачено перехід у режим «Лише читання / завантаження». Збережені матеріали залишаються доступними для перегляду та отримання.
{{< /details >}}

{{< details "Чи можна зберігати в сейфі сертифікати часової мітки?" >}}
Так. Сейф призначений, зокрема, для зберігання сертифікатів, реєстраційних даних, цифрових копій зафіксованих матеріалів і супровідних документів.
{{< /details >}}

{{< details "Чи можна поступово розширювати обсяг?" >}}
Так. Додатковий простір підключається кроками по 100 МБ. Ви можете збільшувати доступний обсяг за потреби.
{{< /details >}}

{{< details "Чи є цифровий сейф резервною копією мого комп'ютера?" >}}
Ні. Це окремий контур зберігання цифрових матеріалів. Він не замінює повноцінну систему резервного копіювання, архівування або відновлення даних.
{{< /details >}}
