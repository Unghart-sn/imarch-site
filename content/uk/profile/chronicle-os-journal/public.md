#### ЗАФІКСУЙТЕ СВІЙ ПРІОРИТЕТ У СВІТОВІЙ НАУЦІ ЗА 7 ДНІВ { .fade-in-up }

Міжнародний рецензований міждисциплінарний науковий журнал **«IMARCH Chronicle OS»**, (Видавництво IMARCH LTD, Лондон, Велика Британія) оголошує прийом публікацій у *Volume 1, Issue 1 (May-June 2026)*. 

> Ми впровадили систему сліпого криптографічного рецензування, яка захищає вашу інтелектуальну власність з першої секунди подання заявки.

&nbsp;

#### Наскрізні стандарти академічної безпеки та неупередженості { .fade-in-up }

- **Double-Blind Peer Review (Абсолютно сліпе рецензування)**: Виключає людський фактор, упередженість або академічний протекціонізм. Рецензент оцінює лише якість дослідження, не знаючи імені автора, його країни чи університету.

- **Криптографічна фіксація пріоритету (SHA-256)**: Наша платформа вирішує головну проблему авторів — захист інтелектуальної власності в процесі розгляду. Хеш вашого сліпого вектора та майстер-файлу публікується миттєво, закріплюючи за вами першість ідеї в міжнародному цифровому просторі.

- **Оптимізований регламент (Без бюрократичних витрат)**: Ми прибрали багатомісячні адміністративні затримки. Автоматизований контур обробки метаданих дозволяє провести аудит та рецензування у фіксований 7-денний термін без втрати академічної якості.

#### Публікаційний контур та інфраструктурний оргвнесок (APC) { .fade-in-up }

*Платформа IMARCH функціонує як некомерційна інфраструктура відкритої науки. Ми не торгуємо «місцями в журналах». Цільові внески авторів спрямовуються на покриття витрат з високотехнологічної незалежної оцінки, криптографічної фіксації та міжнародної реєстрації.*

**Структура цільового фінансування:**

* **£50: Цільовий реєстраційний внесок (Suggested Infrastructure Grant).** Вноситься при первинному поданні. Покриває витрати на первинний ІІІ-аудит антиплагіату, фіксацію SHA-256, роботу сервера реєстру RN-0030 та підготовку матеріалів для незалежного експерта.

* **£100: Фінальний публікаційний внесок.** Вноситься **лише після** того, як стаття успішно пройшла сліпе рецензування та затверджена до публікації. Покриває генерацію британського DOI, вічну індексацію на серверах та офіційний реліз.

Цільова підтримка некомерційної інфраструктури IMARCH Chronicle OS дозволяє забезпечувати пріоритетні терміни обробки та первинної технічної валідації рукопису. При цьому всі статті без винятку проходять незалежне сліпе рецензування (Double-Blind Peer Review). Внесок покриває організацію процесу та не гарантує позитивного рішення рецензентів.

#### Крок 1. Пакет безпеки (Подання заявки) { .fade-in-up }

Ви завантажуєте у форму два файли вашої статті у форматі PDF або Word:

1. **Майстер-Файл:** Повна версія (Ваше ім'я, ВНЗ, контакти, анотація, текст). Він одразу потрапляє до нашого закритого зашифрованого сховища (Сейф).

2. **Сліпий Вектор:** Абсолютно ідентичний текст статті, але з нього **повністю видалені ваші реквізити, ім'я та назва ВНЗ**. Тільки чиста наука.


#### Крок 2. Криптографічний Замок (Миттєвий пріоритет) { .fade-in-up }

Тієї ж миті, як файли завантажено, наша система обчислює їх унікальні цифрові відбитки — **хеші SHA-256**.

* Ми публікуємо картку вашої статті на відкритій міжнародній вітрині передпублікацій `imarch.sbs`.

* **Ваше ім'я приховане від усіх.** Але у відкритому доступі висить англійська анотація та хеші ваших файлів.

* *Навіщо це потрібно?* Це ваш залізний щит. Пошукові системи миттєво індексують сторінку. Ваша ідея захищена від крадіжки на 100%. Якщо хтось спробує запозичити вашу формулу під час рецензування, у вас є лондонський доказ пріоритету.


#### Крок 3. Абсолютно сліпе рецензування (До 7 днів) { .fade-in-up }

Ми беремо ваш **Сліпий Вектор** (файл без імені) та надсилаємо його незалежному міжнародному експерту з нашої Редколегії.

* Професор оцінює виключно якість вашого дослідження. Він не знає, з якого ви університету та з якої країни. Повна неупередженість.

* Реєстраційний внесок £50 забезпечує оперативність аудиту та покриває технічні витрати на проведення рецензування протягом 7 днів.


#### Крок 4. Розкриття сейфа та Реліз { .fade-in-up }

Щойно рецензент ставить візу «Схвалено», ви отримуєте сповіщення.

* Ви вносите фінальний публікаційний внесок £100.

* Система автоматично дістає ваше ім'я із закритого сейфа, пов'язує його з раніше опублікованим хешем Майстер-Файлу, присвоює статті міжнародний індекс **DOI** та переводить статус публікації у статус «Офіційно видано».

async function generateFileHash(inputId, displayId) {
  const input = document.getElementById(inputId);
  const display = document.getElementById(displayId);
  if (!input.files || input.files.length === 0) {
    display.innerText = "SHA-256: очікування файлу...";
    return;
  }
  const file = input.files[0];
  display.innerText = "Розрахунок SHA-256 хеша...";
  try {
    const arrayBuffer = await file.arrayBuffer();
    const hashBuffer = await crypto.subtle.digest('SHA-256', arrayBuffer);
    const hashArray = Array.from(new Uint8Array(hashBuffer));
    const hashHex = hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
    display.innerText = "SHA-256: " + hashHex;
    sessionStorage.setItem('auth_' + inputId + '_hash', hashHex);
  } catch(e) {
    display.innerText = "SHA-256: Помилка обчислення хеша";
  }
}
