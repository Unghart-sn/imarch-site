#### Статус проєкту VIS REALITATIS™ { .fade-in-up }

Проєкт центру реновації та соціальної адаптації ветеранів VIS REALITATIS™ є базовим виробничим проєктом IMARCH LTD (Велика Британія), що реалізується в межах широкої інституційної інфраструктури Chronicle OS Documentation System.

На поточному етапі формується базове ядро системи і перший реєстр співзасновників та учасників.

Включення та визначення рангу співзасновника здійснюється на підставі експертного та/або фінансового внеску в розвиток проєкту, під гарантіями IMARCH LTD (UK).

Реєстраційний номер компанії: 16791765
Інституційна інфраструктура: Chronicle OS Documentation System
