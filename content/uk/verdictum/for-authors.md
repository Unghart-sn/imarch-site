#### ЗАФІКСУЙТЕ СВІЙ ПРІОРИТЕТ У СВІТОВІЙ НАУЦІ ЗА 7 ДНІВ { .fade-in-up }

**VERDICTUM International Journal** (Видавництво IMARCH LTD, Лондон, Велика Британія) оголошує приймання розробок, досліджень і ноу-хау.

> Ми запровадили систему криптографічного рецензування (Skin-in-the-Game), що захищає вашу інтелектуальну власність із першої секунди подання.

&nbsp;

#### Наскрізні стандарти верифікації та безсторонності { .fade-in-up }

- **Double-Blind Peer Review (Цілком сліпе рецензування)**: Виключає людський чинник, упередженість або академічний протекціонізм. Рецензент оцінює лише якість роботи, не знаючи імені автора, його країни чи університету.

- **Криптографічна фіксація пріоритету (SHA-256)**: Платформа розв'язує головну проблему авторів — захист інтелектуальної власності в процесі розгляду. Хеш вашого сліпого вектора та майстер-файлу публікується миттєво, закріплюючи за вами першість ідеї в міжнародному цифровому просторі.

- **Skin-in-the-Game для рецензентів**: Експертиза у VERDICTUM — це економіка участі. Рецензент отримує винагороду за аудит одразу та поділяє довгостроковий відсоток від успіху проєкту. Його вердикт — це фінансово та репутаційно забезпечений знак якості.

#### Публікаційний контур та інфраструктурний внесок (APC) { .fade-in-up }

*Платформа VERDICTUM функціонує як некомерційна інфраструктура суверенного знання. Ми не торгуємо «місцями в журналах». Цільові внески авторів спрямовуються на покриття витрат із незалежної оцінки, криптографічної фіксації та міжнародної реєстрації.*

**Структура цільового фінансування:**

* **£50: Цільовий реєстраційний внесок.** Вноситься під час первинного подання. Покриває витрати на первинний аудит, фіксацію SHA-256, роботу реєстру Verdictum Record (VR) і підготовку матеріалів для незалежного експерта.

* **£100: Фінальний публікаційний внесок.** Вноситься **лише після** того, як робота успішно пройшла сліпе рецензування та затверджена до фіксації. Покриває генерацію DOI, індексацію в реєстрі VERDICTUM та офіційний реліз.

Цільова підтримка некомерційної інфраструктури VERDICTUM забезпечує пріоритетні строки опрацювання та первинної технічної валідації. При цьому всі роботи без винятку проходять незалежне сліпе рецензування. Внесок покриває організацію процесу та не гарантує позитивного рішення рецензентів.

#### Крок 1. Пакет безпеки (Подання заявки) { .fade-in-up }

Ви завантажуєте у форму два файли вашої роботи у форматі PDF або Word:

1. **Майстер-Файл:** Повна версія (Ваше ім'я, ВИШ/організація, контакти, анотація, текст). Він одразу йде до нашого закритого зашифрованого сховища (Secure Vault).

2. **Сліпий Вектор:** Цілком ідентичний текст роботи, але з нього **повністю вилучено ваші реквізити, ім'я та назву організації**. Лише чиста суть.

#### Крок 2. Криптографічний Замок (Миттєвий пріоритет) { .fade-in-up }

Тієї ж секунди, як файли завантажено, наша система обчислює їхні унікальні цифрові відбитки — **хеші SHA-256**.

* Ми публікуємо картку вашої роботи на відкритій вітрині передпублікацій `imarch.ltd`.

* **Ваше ім'я приховано від усіх.** Але у відкритому доступі висить анотація та хеші ваших файлів.

* *Навіщо це потрібно?* Це ваш залізний щит. Пошукові системи миттєво індексують сторінку. Ваша ідея захищена від крадіжки на 100%. Якщо хтось спробує запозичити вашу формулу під час рецензування, у вас є лондонський доказ пріоритету.

#### Крок 3. Цілком сліпе рецензування (До 7 днів) { .fade-in-up }

Ми беремо ваш **Сліпий Вектор** (файл без імені) та надсилаємо його незалежному міжнародному експерту з нашої Редколегії.

* Експерт оцінює винятково якість вашого дослідження. Він не знає, з якої ви організації та з якої країни. Повна безсторонність.

* Реєстраційний внесок £50 забезпечує оперативність аудиту та покриває технічні витрати на проведення рецензування протягом 7 днів.

#### Крок 4. Відкриття сейфа та Реліз { .fade-in-up }

Щойно рецензент ставить візу «Схвалено», ви отримуєте повідомлення.

* Ви вносите фінальний публікаційний внесок £100.

* Система автоматично дістає ваше ім'я із закритого сейфа, пов'язує його з раніше опублікованим хешем Майстер-Файлу, присвоює роботі міжнародний індекс **DOI** та переводить статус у «Офіційно зафіксовано».

async function generateFileHash(inputId, displayId) {
  const input = document.getElementById(inputId);
  const display = document.getElementById(displayId);
  if (!input.files || input.files.length === 0) {
    display.innerText = "SHA-256: очікування файлу...";
    return;
  }
  const file = input.files[0];
  display.innerText = "Розрахунок SHA-256 хешу...";
  try {
    const arrayBuffer = await file.arrayBuffer();
    const hashBuffer = await crypto.subtle.digest('SHA-256', arrayBuffer);
    const hashArray = Array.from(new Uint8Array(hashBuffer));
    const hashHex = hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
    display.innerText = "SHA-256: " + hashHex;
    sessionStorage.setItem('auth_' + inputId + '_hash', hashHex);
  } catch(e) {
    display.innerText = "SHA-256: Помилка обчислення хешу";
  }
}
