🔒 The computation is performed entirely within your browser via the Web Crypto API. The file is not uploaded to a server and does not leave your computer.

 

How it works

  1. Select a file — click on the upload area or drag a file into it.
  2. Obtain the hash — the SHA-256 fingerprint will appear automatically.
  3. Copy the value — click ‘Copy’ and use it for verification.

The tool is useful for verifying the integrity of documents fixed in the VERDICTUM registry. If the checksum of a file matches the one indicated in the publication details, then the document has not been modified since registration.
