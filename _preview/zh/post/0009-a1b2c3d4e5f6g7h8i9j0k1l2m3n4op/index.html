介于 Vis Realitatis / IMARCH 项目 与 专家 ___________________________

1. 总则

本谅解备忘录（以下简称"备忘录"）规定了 Vis Realitatis / IMARCH 项目（以下简称"项目"）与专家（以下简称"专家"）在项目的人道主义、研究和教育倡议框架内的合作原则和范围。

本备忘录不是服务合同，不自动产生各方的财务义务，除非在单独协议中明确规定的情况除外。

2. 合作目的

本备忘录的目的是：

  • 专家参与项目的方法论、研究和组织解决方案的制定、验证和测试；
  • 协助建立为退伍军人、家庭和社区提供身心情感支持的可持续系统；
  • 为项目的科学方法、分析和专家基础做出贡献。

3. 专家的地位和角色

专家以以下身份参与项目：

  • 在其专业能力范围内的独立专家；
  • 研究和方 法论过程的顾问和/或参与者；
  • 项目专家或咨询圈的成员（无管理权限）。

专家不是项目的雇员、承包商或代表，除非另有单独文件规定。

4. 专家的参与形式

参与形式可包括（但不限于）：

  • 专家咨询；
  • 参与工作会议、试点项目、焦点小组；
  • 审查材料、方法、协议；
  • 参与制定建议、报告和分析结论；
  • 在测试和扩展解决方案阶段提供专家支持。

具体的参与范围和格式由双方另行商定。

5. 财务条件

  • 专家的基本参与可以无偿进行，作为对一个人道主义和研究项目的贡献。
  • 如有资金（赠款、捐助者资金），可提供一次性或分阶段补偿，通过单独协议或附件形式化。
  • 补偿事实不影响专家的独立地位及其专家结论。

6. 保密和道德

专家承诺：

  • 保护项目参与者的敏感数据机密性；
  • 在职业道德框架内行事；
  • 不利用获得的信息损害项目或其参与者。

项目承诺：

  • 正确使用专家的贡献，并注明作者身份（如适用）；
  • 在公开材料中不歪曲专家结论。

7. 知识产权

  • 专家个人材料的版权归专家所有。
  • 项目有权在其使命范围内使用合作成果，并注明来源。
  • 其他条件必要时通过单独协议规定。

8. 有效期

本备忘录自签署之日起生效，直至任何一方通过书面通知终止为止。

9. 最后条款

本备忘录反映了各方的善意意图，并基于以下原则：

  • 透明度，
  • 相互尊重，
  • 人道主义责任，
  • 科学和专业的诚信。
